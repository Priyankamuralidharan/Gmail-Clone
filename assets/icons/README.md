All icons used in this project (logo, folder icons, action icons) are inlined as SVG directly inside the HTML/JS, so no PNG files are required for the app to work.

Drop your own images here (e.g. `gmail-logo.png`, `default-user.png`) if you'd like to swap the inline SVGs for custom artwork — just update the `<img>`/`<svg>` references in `inbox.html` and `index.html` accordingly.
